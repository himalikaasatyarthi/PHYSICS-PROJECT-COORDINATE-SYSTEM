ABOUT THE PROJECT

Understanding Space Through Mathematics

Multiverse of Coordinates is an educational physics project designed to demonstrate how different coordinate systems represent the same point in space.

The project combines C programming, mathematical transformations, web technologies and interactive three-dimensional visualization to make abstract concepts easier to understand.
